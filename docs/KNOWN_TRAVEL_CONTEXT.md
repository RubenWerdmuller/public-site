# Bekende startcontext

Bron: het door de gebruiker aangeleverde inspiratiedocument van 7 oktober 2026. Rijen hebben bron `explicitly_stated`; waar de bron ruimte laat, blijft zekerheid beperkt. Dit zijn startgegevens voor deze persoonlijke app, geen profiel dat uit nieuwe gebruikersnamen wordt geraden.

| Onderwerp | Startgegeven | Betekenis |
| --- | --- | --- |
| Vervoer | Eigen auto | Sterke voorkeur |
| Vliegen | Liever niet | Sterke voorkeur; hardheid nog bevestigen |
| Duur | Denkbereik 1,5–6 maanden | Open kernvraag, geen vaststaand maximum |
| Vertrek | Nog onbekend | Open kernvraag |
| Budget | Nog onbekend | Open kernvraag, maandbudget voor twee |
| Klimaat | Liefst warm en droog, 20–35 °C | Zachte grens, bijzondere ervaring kan bespreekbaar zijn |
| Zee | Fijn | Lichte voorkeur, geen dealbreaker |
| Communities/spiritualiteit | Interesse | Vorm en intensiteit nog ontdekken |
| Leren/vrijwilligen | Interesse | Uren, voorwaarden en inhoud nog ontdekken |
| Spelen/langzaam reizen | Interesse | Niet uitsluitend toeristische afvinklijstjes |
| Vegetarisch/vegan | Vriendelijk aanbod fijn | Zacht, nooit standaard een regio uitsluiten |
| Roebies bootdroom | Een paar dagen meezeilen, leren en mogelijk aan boord slapen | Persoonlijke wens, autoreis blijft basis |
| Oelies dromen | Nog ophalen | Persoonlijk open item, niets invullen |

Aanpassingen gaan via Instellingen → Onze reisuitgangspunten. De server leest die databasegegevens voor volgende sets. De seed gebruikt `ON CONFLICT DO NOTHING` en overschrijft aanpassingen niet. Alle proefwijzigingen op `/test` verdwijnen bij vernieuwen of Opnieuw.

Nog te ontdekken: daadwerkelijke vertrekmaand en duur, gezamenlijke financiële ruimte, harde onder-/bovengrenzen, rijbelasting, sociale/privébalans, voorwaarden voor meewerken, welke workshops ieder echt wil en wat er gebeurt bij verschillen. De vragenbank houdt daarvoor bewust ruimte.
